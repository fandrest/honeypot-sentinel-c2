Términos y Condiciones de Acceso al Servicio WiFi-Free

Al acceder a esta red inalámbrica gestionada de cortesía, el usuario reconoce y acepta de forma expresa las siguientes cláusulas de servicio:

1. Naturaleza del servicio: El presente acceso se proporciona con fines exclusivamente de investigación académica y monitorización de tráfico en redes locales bajo el protocolo IEEE 802.11.

2. Registro de metadatos: Para garantizar la estabilidad del servicio, el sistema podrá registrar descriptores técnicos de la sesión, incluyendo identificadores lógicos de red, parámetros de resolución de host (DNS), cabeceras de agentes de usuario y métricas de latencia.

3. Uso de los datos: La información recolectada se procesará de forma agregada para el análisis de patrones de interacción en entornos controlados de ciberseguridad. No se garantiza la privacidad absoluta del tráfico cifrado.

4. Limitación de responsabilidad: La entidad no se hace responsable de las posibles redirecciones o fallos en la resolución de dominios externos durante la sesión activa.
